# Azure SRE Agent event lab

This runnable sample contains the application, infrastructure, scenario scripts,
captured evidence, and notification assets used by the Azure SRE Agent topic.

From the repository root:

```bash
cd docs/services/azure-monitor/azure-sre-agent/samples/event-lab
azd up
```

Follow the [event lab instructions](../../event-lab/index.md) for setup,
scenario execution, validation, and cleanup.
