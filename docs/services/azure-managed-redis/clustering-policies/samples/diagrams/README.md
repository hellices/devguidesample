# Clustering policy diagram

[정책 개요](../../index.md)에서 사용하는 연결 모델 그림의 단일 원본입니다.
`clustering-policies.excalidraw`는 편집 원본이고 `clustering-policies.svg`는
게시용 내보내기입니다. 언어별 문서와 장애 사례에서는 정책 개요를
참조하며 그림을 중복 저장하거나 다시 게시하지 않습니다.

## 수정·검증

1. Excalidraw 또는 VS Code Excalidraw 확장에서 원본을 수정합니다.
2. 같은 이름의 SVG로 내보내 이 sample의 SVG를 갱신합니다.
3. 저장소 루트에서 `mkdocs build --strict`를 실행합니다.
   `sample.yml`이 지정한 topic의 `images/clustering-policies.svg`에 게시됩니다.

별도의 실행 리소스나 정리할 클라우드 자원은 없습니다.
Microsoft Learn의 아키텍처 PNG는 sample에서 복제하지 않고
topic의 [images/](../../images/)에 보관합니다.
